# 🏨 Booki – Projet Front-End

## 👨‍💻 À propos

Booki est un projet **front-end** mettant en pratique mes compétences en **HTML** et **CSS**, réalisé à partir d’une maquette professionnelle.  
Ce projet met l’accent sur le **responsive design**, la **structure sémantique** et la qualité de l’intégration.

---

## 🧠 Compétences démontrées

✅ Intégration web responsive  
✅ HTML5 sémantique et accessible  
✅ CSS moderne (Flexbox)  
✅ Organisation claire du code  
✅ Respect d’une maquette professionnelle  

---

## 🛠️ Stack technique

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome

---

## 📐 Responsive Design

L’interface s’adapte parfaitement aux différents écrans :
- 🖥️ Desktop
- 📱 Mobile
- 📐 Tablette
